# Sprint Planning Assistant 用户指南

## 概述

Sprint Planning Assistant 是一个集成在 Jira 中的 AI 驱动工具，旨在帮助敏捷团队优化 Sprint 规划过程。它提供智能分析、工作负载管理、假期影响评估和实时指标监控。

## 功能特性

### 🤖 AI 驱动的推荐引擎
- **容量优化建议**：自动检测过载或未充分利用的情况
- **风险缓解建议**：识别潜在的 Sprint 风险并提供解决方案
- **流程改进建议**：基于团队表现提供流程优化建议
- **置信度评分**：每个建议都包含可信度评估

### 👥 高级团队工作负载管理
- **可视化工作负载分布**：直观显示团队成员的工作分配
- **智能重新分配**：基于技能匹配的自动工作负载平衡
- **容量预测**：未来 Sprint 的容量规划和预测
- **技能矩阵管理**：团队成员技能和可用性管理

### 🏖️ 假期影响分析
- **多地区假期支持**：支持中国、美国、印度等多个地区
- **容量减少计算**：精确计算假期对团队容量的影响
- **自动调整建议**：基于假期影响的 Sprint 范围调整建议

### 📊 实时 Sprint 指标仪表板
- **燃尽图**：实时 Sprint 进度跟踪
- **速度趋势分析**：团队历史速度和趋势分析
- **容量利用率监控**：团队容量使用情况的实时监控
- **瓶颈检测**：自动识别和报告潜在瓶颈

## 安装和设置

### 前提条件
- Jira Software (Cloud 或 Server)
- 现代浏览器 (Chrome, Firefox, Safari, Edge)
- 团队管理员权限（用于初始设置）

### 安装步骤

1. **浏览器扩展安装**
   ```bash
   # 开发模式安装
   cd frontend
   pnpm install
   pnpm dev
   ```

2. **后端服务部署**
   ```bash
   # 后端服务启动
   cd backend
   pip install -r requirements.txt
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

3. **配置环境变量**
   ```bash
   # 在 .env 文件中配置
   AZURE_OPENAI_API_KEY=your_api_key
   AZURE_OPENAI_ENDPOINT=your_endpoint
   AZURE_OPENAI_DEPLOYMENT_NAME=your_deployment
   ```

## 使用指南

### 基本使用流程

1. **访问 Jira Board 或 Backlog 页面**
   - 导航到您的 Jira 项目的 Board 或 Backlog 视图
   - Sprint Planning Assistant 将自动检测并显示在页面顶部

2. **启动 Sprint Planning Assistant**
   - 点击 "Sprint Assistant" 按钮
   - 工具将自动检测当前 Board ID 和 Sprint 数据

3. **查看分析结果**
   - **概览标签页**：查看 Sprint 基本信息和 AI 建议
   - **工作负载标签页**：管理团队工作负载分配
   - **假期影响标签页**：查看假期对 Sprint 的影响

### 详细功能使用

#### 📊 概览标签页

**Board 信息**
- 显示当前 Board ID、名称和项目信息
- 自动检测和验证 Board 配置

**Sprint 概览**
- Sprint 名称、状态和基本统计
- 任务数量、Story Points 总数
- 团队成员数量

**关键指标**
- 总点数、平均速度、利用率
- 实时更新的性能指标

**AI 建议**
- 分类显示的智能建议
- 每个建议包含具体的行动步骤
- 置信度和优先级指示

#### 👥 工作负载标签页

**团队工作负载表格**
- 成员姓名、当前 Sprint 点数、遗留点数
- 总负载、容量利用率、状态指示器
- 交互式成员详情查看

**工作负载重新分配**
1. 点击 "重新分配" 按钮进入重新分配模式
2. 选择过载成员的任务点数
3. 从下拉菜单选择目标成员
4. 确认重新分配操作

**状态指示器说明**
- 🟢 **正常** (70-100% 利用率)：工作负载适中
- 🟡 **偏高** (100-120% 利用率)：需要关注
- 🔴 **过载** (>120% 利用率)：需要立即调整

#### 🏖️ 假期影响标签页

**假期概览**
- 显示 Sprint 期间的所有假期
- 按地区分类的假期信息
- 工作日影响统计

**受影响团队成员**
- 列出所有受假期影响的成员
- 显示具体的容量减少百分比
- 假期详情和影响天数

**容量调整建议**
- 基于假期影响的自动调整建议
- 一键应用推荐的容量调整
- 保守调整选项

#### 📈 实时指标仪表板

**燃尽图**
- 理想进度线 vs 实际进度
- 实时更新的 Sprint 进度
- 完成概率预测

**速度趋势**
- 历史 Sprint 速度对比
- 团队速度趋势分析
- 平均速度基准线

**容量分析**
- 圆形仪表盘显示利用率
- 详细的容量分解
- 团队规模和人均负载

## 故障排除

### 常见问题

**Q: Sprint Planning Assistant 没有显示在 Jira 页面上**
A: 
1. 确认您在正确的 Jira Board 或 Backlog 页面
2. 检查浏览器扩展是否正确安装和启用
3. 刷新页面并等待几秒钟让工具加载

**Q: 无法检测到 Board ID**
A:
1. 确认 URL 包含正确的 Board 信息
2. 检查您是否有访问该 Board 的权限
3. 尝试手动刷新工具

**Q: AI 建议不准确或不相关**
A:
1. 确保 Sprint 数据完整且最新
2. 检查团队成员信息是否正确配置
3. 考虑提供更多历史数据以提高准确性

**Q: 性能较慢或响应时间长**
A:
1. 检查网络连接状态
2. 清除浏览器缓存
3. 联系管理员检查后端服务状态

### 错误代码

- **E001**: Board ID 检测失败
- **E002**: Sprint 数据解析错误
- **E003**: API 连接超时
- **E004**: 权限不足
- **E005**: 数据格式错误

### 联系支持

如果遇到技术问题或需要帮助：
1. 查看浏览器控制台的错误信息
2. 记录重现问题的步骤
3. 联系技术支持团队

## 最佳实践

### Sprint 规划建议

1. **定期更新团队信息**
   - 保持团队成员技能信息最新
   - 及时更新工作安排和可用性
   - 记录假期和请假计划

2. **合理设置容量**
   - 基于历史数据设置现实的容量目标
   - 考虑团队成员的经验和技能水平
   - 为意外情况预留缓冲时间

3. **关注 AI 建议**
   - 定期查看和评估 AI 推荐
   - 根据团队实际情况调整建议
   - 跟踪建议实施后的效果

4. **监控关键指标**
   - 定期检查团队速度趋势
   - 关注容量利用率变化
   - 及时识别和解决瓶颈

### 团队协作

1. **透明的工作负载分配**
   - 公开讨论工作负载分配
   - 鼓励团队成员主动沟通容量问题
   - 建立定期的负载平衡检查

2. **技能发展规划**
   - 识别团队技能缺口
   - 制定技能提升计划
   - 鼓励知识分享和交叉培训

3. **持续改进**
   - 定期回顾 Sprint 规划效果
   - 收集团队反馈和建议
   - 不断优化规划流程
